PS4 IPTV - HARDWARE CHECKPOINT 3.2: M3U / M3U8 SOURCES + NEAR-BLACK UI + FAST DS4 SCROLLING + FONTS
=====================================================================================================
Build @BUILD@ (v0.2.0, title IPTV00002). PKG IV0001-IPTV00002_00-IPTV000020002000.pkg sha256 @SHA@

What changed since Checkpoint 3.1 (build 941f8ec):
  - Sources: "Add Source" offers Xtream Codes or M3U / M3U8 Playlist. Playlist sources are LIVE TV ONLY:
    groups (group-title / #EXTGRP), logos (tvg-logo), search, favorites, Recently Watched, Refresh Playlist,
    Playlist Info. No Movies / Series / Continue Watching / downloads for playlists (never guessed).
    "Profiles" are called "Sources" now. Your Xtream profile is migrated automatically (profiles.json v2; the
    original file is kept as /data/PS4IPTV/profiles.v1.json so Checkpoint 3.1 could still be reinstalled).
  - Near-black / charcoal theme everywhere (one central palette, contrast checked on the PC).
  - DS4: holding a direction accelerates: 0.3 s delay, then a step every 90 ms, 60 ms (after 1 s), 40 ms
    (after 2 s), 30 ms (after 3.5 s). Left stick pushed all the way: 1.35x faster. Lists and poster grids
    now GLIDE to their new position (Settings > Smooth scrolling turns that off).
  - Text: fallback fonts for Arabic, Hebrew, Armenian, Georgian, Japanese, Korean and Chinese characters;
    Arabic / Hebrew lines are shown right-to-left with joined Arabic letters (basic shaping).
  - PKG is 40.3 MB (+4.3 MB: the two fallback fonts).

This PKG contains NO credentials and NO playlists. Install it OVER the existing "PS4 IPTV": your Xtream
profile (now "source"), favorites, history, positions, downloads and settings are kept.

Prepare before starting:
  P1 = your provider's M3U playlist address, if it offers one. For Xtream panels it usually looks like
       http://<server>:<port>/get.php?username=<user>&password=<pass>&type=m3u_plus&output=ts
       (type it on the on-screen keyboard; it is shown afterwards only as "server:port/get.php").
       Any other M3U / M3U8 playlist you are entitled to use works too.
  P2 = (optional, for step 38) a large synthetic playlist: on the PC run
         python -I scripts\make-synthetic-playlist.py 25000 synthetic-25000.m3u
       and copy synthetic-25000.m3u by FTP to /data/PS4IPTV/playlists/ on the PS4 (create the folder).
       Its channels point to example.com: they browse / search / favorite, but do not play.
  P3 = (optional) one playlist entry whose stream URL starts with https:// (for step 18).

HARDWARE UNKNOWNS (what these steps decide):
  U1 scissor clip (steps 34-46): while a list glides, the app clips the moving rows with GL scissor
     (glScissor was already imported by the 3.1 build, but never used). Wrong: lists vanish, flicker, rows
     drawn over the header / hint bar, or the video / other screens become partly invisible after scrolling.
     If so: Settings > Smooth scrolling = Off must make everything normal again - report both.
  U2 fallback fonts (steps 47-51): two more font files in the same glyph atlas system. Wrong: boxes where
     the text test shows Arabic / Japanese / Korean, garbled letters, or Latin text breaking after
     non-Latin text was shown.
  U3 playlist download size: a large playlist (tens of thousands of entries) is downloaded and parsed on a
     worker thread (PC: 25,000 entries parse + index in ~0.12 s; the PS4 is slower). Wrong: UI frozen.
  U4 HTTPS streams: the playback FFmpeg build has no https protocol (audited). Expected: a clear message,
     never a hang (step 18).
