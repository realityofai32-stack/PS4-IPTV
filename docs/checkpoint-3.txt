What changed since Checkpoint 2.5:
  - The whole interface is English by default; Settings > Language switches to Türkçe (and back) at once.
    Provider titles, channel names, categories and plots are never translated.
  - The text rendering test no longer opens by itself. It is in Settings > Diagnostics > Text rendering test.
  - Playback Options (OPTIONS while a movie / episode plays): every audio and subtitle track of the file,
    + "Video display mode" (Auto / Original, Fit, Fill / Crop, Stretch, 16:9, 4:3) and "Zoom" (100-125 %),
    + "Use display settings as default". Settings has Default video display mode and Default zoom.
  - Offline downloads of movies and episodes: Movie detail "↓ Download", episode rows (Square = download,
    OPTIONS = more), Home > Downloads, Settings > Storage & downloads. Downloads pause while a video plays.
  - When the provider cannot be reached at start: "Continue offline" (saved lists + downloads).
  - Home has 7 tiles (Downloads added). Version 0.2.0.

This PKG contains NO credentials. Install it OVER the existing "PS4 IPTV" (same title): profile, favorites,
history and positions are kept. Your settings are kept, except the language: it starts in English (the
language setting did not exist before). Downloads are stored in /data/PS4IPTV/downloads/.

Pick for the download tests: a SHORT movie (small file, e.g. a cartoon or a short film, a few hundred MB) =
"DM1", and one series episode = "DE1". Note their names. Keep the PS4 on the same network as in 2.5.

HARDWARE UNKNOWNS (what these steps decide):
  U1 free space / large files: the app now calls two system functions pPlay never used (fstatfs for free
     space, ftruncate to cut a partial file back). If the app does not start at all (step 1), this is the
     prime suspect - tell me immediately. If it starts but step 34 shows "Unknown" free space, fstatfs is
     unavailable (downloads still work; the space check then relies on write errors).
  U2 display modes: Fill / Stretch / 16:9 / 4:3 / Zoom only change mpv's picture rectangle (same shader as every
     video so far). A black screen or "This video format is not supported on PS4 yet" right after changing the
     mode would mean a shader difference - note which mode.
  U3 a local file through mpv (offline playback) - the same player, but the first time a file on /data is played.
  U4 speed: a download on the PS4 network stack (libcurl, the same library as the API and logos).
