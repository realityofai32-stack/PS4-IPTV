V7 IPTV - HARDWARE CHECKPOINT V7-UI-1: BRAND, DESIGN SYSTEM, ACCENT COLORS, NEW HOME / DETAILS / SETTINGS
======================================================================================================
Branch feature/v7-ui-refresh (local only). Version 0.2.0, title IPTV00002 (unchanged).
Build ID and PKG SHA-256: see build/checkpoint-v7-ui-1/BUILD.txt and SHA256SUMS.txt.

What changed since Checkpoint 3.2 (build 87f5bcd, v0.2.0):
  - The app is called V7 IPTV: new V7 symbol in every screen header, on Home, onboarding, About and the PS4
    home screen icon; PKG display name "V7 IPTV". Title ID, content ID and /data/PS4IPTV/ are UNCHANGED, so
    the PKG installs over v0.2.0 and keeps sources, favorites, history, positions, downloads and settings.
  - Deep-navy theme with a user-chosen accent: Settings > Appearance > Accent color (V7 Blue, Cyan, Teal,
    Green, Purple, Magenta, Red, Orange, White). Saved in settings.json ("accentColor"); older files get V7 Blue.
  - Home: top navigation (Home / Live TV / Movies / Series, then Search / Favorites / Downloads / Settings
    icons), a hero for the last Continue Watching item (or a "What would you like to watch?" start state),
    rails: Continue Watching, Recently Watched, Favorites.
  - Movie / Series details: poster-derived backdrop, actions under the plot (Play / Resume dominant), episode
    rows with stills when the provider has them, season tabs.
  - Settings: categories | settings | description. Add Source: two large choices.
  - Player: Playback Options grouped (Audio, Subtitles, Video, Subtitle style, Technical info); HUD bands fade
    into the video; shorter hint bars everywhere.
  - Media stack, downloads, search ranking, parsers, storage formats: unchanged.

This PKG contains NO credentials and NO playlists. Install it OVER the existing "PS4 IPTV" (it will show as
"V7 IPTV" afterwards). Take screenshots (SHARE button) of every screen marked [SHOT].

HARDWARE UNKNOWNS (what these steps decide):
  U1 vertex-alpha gradients over artwork (Home hero, detail backdrops, HUD fades). Expected: smooth dark fades.
     Wrong: black / white rectangles, banding stripes, or the backdrop drawn over the text.
  U2 enlarged poster as backdrop: a 340x510 poster stretched ~4x with bilinear filtering. Expected: a soft,
     dimmed colour wash (blur-like). Wrong: hard pixel blocks, or a bright image fighting the text.
  U3 home page scroll: the whole page moves when a lower rail is focused (glides with Smooth scrolling On).
     Wrong: rails drawn over the navigation or the hint bar, jitter, or slow input while it moves.
  U4 rebuild on accent change: applying an accent rebuilds every screen (like a language change). Wrong:
     crash, missing images afterwards, or a long freeze (> 1 s).
  U5 vector shapes: V7 symbol, nav icons (magnifier, star, arrow, gear), season chips. Wrong: jagged or
     broken shapes, a star drawn as a pentagon fan with holes, gear teeth misplaced.
